# Debian-redesign

**Debian-redesign** — проект, представляющий собой редизайн официального сайта операционной системы Debian. Дизайн проекта был создан на основе главной страницы [официального сайта Debian](https://www.debian.org/).

## Что было сделано

### 1. Обновлённый дизайн

Разработан обновлённый макет в Figma: [Figma](https://www.figma.com/design/6sr3mmkioopHE7zsMg9OAi/Untitled--Copy-?node-id=78-2&t=FiOxbst2qfV9JCjy-1).

### 2. Переключение между языками

Реализовано переключение между русским и английским языками. Сайт автоматически выбирает соответствующие страницы.

### 3. Динамическое обновление релизов

Информация в модуле «Предыдущие релизы» подгружается из JavaScript-объекта.

### 4. Интерактивные элементы

Реализованы:
- Слайдер новостей с фильтрацией.
- Аккордеон.

### 5. Скачивание файлов

Реализована возможность скачивания файлов.

### 6. Адаптивная вёрстка

Интерфейс адаптирован под различные размеры экранов. Реализовано бургер-меню.

### 7. Динамическая генерация элементов

`Header` и `Footer` формируются с помощью JavaScript.

## Используемые технологии

Большая часть действий пользователя обрабатывается с использованием библиотеки **jQuery**. Слайдер написан на **Vanilla JavaScript**.
